# v1 发布摘要

## Feature Summary
- Next.js App Router 前台 + Admin（/admin）
- Directus 作为 CMS/资产中心，提供产品、分类、RFQ 配置
- PostgreSQL 用于业务数据与 Directus 底层存储
- Redis 承载缓存/会话/限流（按需）
- Meilisearch 产品检索，支持重新索引脚本
- Nodemailer SMTP 流程，在 RFQ / Admin 审批中发送通知

## Security Baseline
- `.env` 私下维护，仓库仅提供 `infra/.env.example`
- HTTP 层建议按环境切换 CSP/HSTS：本地/开发宽松、生产严格
- 所有容器通过内部网络通信，仅暴露反向代理和 Directus（如需）
- Directus Admin Token、NextAuth Secret、SMTP 凭证均通过环境变量注入
- RFQ/登录 API 具备节流与审计钩子，可在 `withSecurityContext` 中集中管理

## Known Limitations
- 仓库不包含真实 Directus 数据或文件，仅提供 schema 快照和 demo seed（稍后补充）
- docker compose 当前主要面向本地/测试，生产仍需自行接入反向代理与证书
- 管理端产品 CRUD、RFQ、Logout 等交互仍在修复中（后续 Task Pack）
- 没有托管级别备份策略，需要按 `docs/runbooks/backup-restore.md` 手工执行

## Verification Checklist
- `npm install && npm run lint && npm run build`
- `docker compose -f infra/docker-compose.yml up -d` 并确认 postgres / redis / meili / directus 均 healthy
- `npx prisma migrate deploy`
- Directus schema 通过脚本成功应用，产品/分类等集合可见
- Demo seed + Meilisearch 重新索引完成
- 访问 `http://localhost:3000` 与 `/admin` 正常渲染，无关键 CSP/网络错误
